# specrig/specrig

The core of specrig for PHP: the harness, the stand-ins, the contract check, the
records, the Behat binding and the `specrig` command. A service installs it through
its framework's adapter:

```bash
composer require --dev specrig/laravel
```

or `specrig/symfony`. How to lay the harness out and write the cases:
[specrig/specrig-php](https://github.com/specrig/specrig-php#getting-started).

This repository is a read-only copy of `packages/specrig` in specrig-php, kept in
step by specrig-php's release workflow. Issues and changes go to
[specrig-php](https://github.com/specrig/specrig-php).
